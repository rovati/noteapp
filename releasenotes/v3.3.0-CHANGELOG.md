# Maintenance update

This release contains Flutter and dependencies updates. Specifically, it moves to AGP9 to provide better reproducibility of the APK builds.

Have fun!

## How to install

1. Download the apk for your architecture
2. From your file explorer, tap on the apk file and follow the instructions
3. Done! Enjoy the app, and if you encounter any bugs please use the corresponding section to report them (link also available in-app under the settings page).
